A lightweight cross platform desktop SEO crawler

Shouting Robin runs on Linux, macOS and Windows. It crawls a site from your machine, can render pages in Chrome, and sorts the findings by priority. Product pages get their own checks, including GTIN check digits.

Checks

The results of a crawl are split into tabs. Most tabs have filters for the problems they check, and any tab can be exported as CSV.

Crawl and response

Every URL with its status code, content type, indexability, crawl depth and link score. Broken links, redirect chains and loops, and URLs with parameters are flagged.

  • External

On the page

Titles and descriptions measured in characters and in pixels, H1 and H2 checks, exact and near duplicate content, and images that are broken, over 100 KB, or missing alt text or size attributes.

  • Meta Desc
  • H1
  • H2
  • Content
  • Images

Indexing

Canonicals, robots directives, hreflang return tags, language codes and x-default, and sitemap URLs that are not indexable, do not return 200 or were not found by following links.

  • Canonicals
  • Directives
  • Hreflang
  • Sitemaps

Quality

Structured data checked against the required and recommended properties for types such as Product, Article, Recipe and JobPosting, and missing security headers. Chrome crawls add LCP, CLS, FCP and TTFB, and axe-core accessibility audits.

Tour

Select a row to show the page in the details panel next to the grid.

Page details

The details panel shows the status and indexability of the page, its title, description and headings with their lengths, and a preview of the search result. Structured data, link metrics and response headers follow below.

Inlinks and Outlinks list the links to and from the page.

Accessibility

Chrome crawls run axe-core on every page. Each violation is a row with its rule, impact, the element it found and its HTML.

The Performance tab in the same crawl has LCP, CLS, FCP and TTFB for each page.

Changes

A crawl is compared with the previous crawl of the same URL. The Changes tab lists pages that were added or removed, and pages whose status, indexability, title, H1, meta description or word count changed.

Earlier crawls are listed in the sidebar. Open one to see its results, or recrawl it with the settings it ran with.

Ecommerce

A page counts as a product page when it has Product structured data or an og:type of product. The Ecommerce tab reads the product's data and flags:

  • Products without a price, availability, SKU, GTIN, brand or image
  • Products without review or aggregateRating
  • GTINs with the wrong length or check digit
  • Indexable product pages that are out of stock
  • Product pages without BreadcrumbList data

Valid GTIN-13

Weights alternate 3 and 1 from the right. The check digit brings the sum up to the next multiple of ten. The crawler runs the same check on every product.

Features

History

Every crawl is saved in a local SQLite database. Open, recrawl or delete earlier crawls from the sidebar.

Chrome rendering

Turn on Chrome to crawl pages after JavaScript has run. The server HTML is fetched as well, so content that only exists after rendering is flagged.

Reports

Export the Overview as a PDF report with sample URLs for each finding, the current tab as CSV, or every tab as CSV files at once.

Over 90 checks

From title pixel widths and hreflang return tags to GTIN check digits and security headers. Each check is a filter on its tab, so the URLs it flags are one click away.
